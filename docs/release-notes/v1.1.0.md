**Dovetail now installs like a normal Windows program.**

v1.0.0 shipped a zip of 14 loose files that needed the .NET runtime installed separately, and
its first-run window had a layout bug that hid the Finish button. Both are fixed. If you are
on v1.0.0, this is the release to take.

---

## Download

**[`DovetailSetup-1.1.0.exe`](https://github.com/Isaac-Onyango-Dev/Dovetail/releases/latest)** —
download, run, done.

No prerequisites. No runtime to install first. Nothing to unzip or keep track of. It installs
to Program Files, adds a Start Menu entry and an Add/Remove Programs entry, and offers to start
Dovetail and run first-time setup when it finishes.

A portable `.zip` is still attached for anyone who would rather not install anything.

---

## What's new

**A real installer.** One `DovetailSetup-1.1.0.exe`, 49 MB, self-contained. Where v1.0.0 asked
you to unzip a folder, keep it somewhere sensible, go and find the .NET 8 Desktop Runtime, and
re-run the exe by hand every time, this installs once and stays installed.

**The .NET runtime is bundled.** The build is now self-contained, so Dovetail works on any
Windows 10 or 11 x64 machine with nothing else on it. This is the whole reason the download
went from 2 MB to 49 MB, and it is the right trade: "go and install a runtime first" is a dead
end for most of the people this is for.

**An uninstaller that actually undoes things.** Uninstalling from Add/Remove Programs reverses
what Dovetail did to the machine — the auto-start entry, Dovetail's own HidHide allow-list
entries, and un-hiding any device Dovetail hid — rather than only deleting files. Leaving those
behind would keep your pad cloaked with Dovetail no longer allowed to see it, and nothing on
the machine explaining why.

**Your calibration survives an uninstall.** It lives in `%LOCALAPPDATA%\Dovetail`, it costs a
full input sweep per pad to recreate, and an uninstall is not consent to destroy it. Verified
by a full install → uninstall → reinstall round trip.

## Fixed

**The Finish button in first-time setup was unreadable and looked broken.** The status message
and the button were laid out in the same grid cell with no columns between them, so the message
ran full-width underneath the button and the button painted over it — the sentence disappeared
mid-word and the button looked unclickable. They are now in separate columns.

**The setup window could not be resized.** It was fixed at `CanMinimize`, so when content did
not fit there was nothing you could do about it. It resizes now.

**The setup window opened too short for its own content.** At 620 units, step 1 was scrolled out
of view — so the message saying "Use **Set up now**" pointed at a button that was off screen.
It now opens at 820, clamped to whatever your display can actually give.

**13 unused localisation folders removed** from the build. WPF and WinForms ship translated
exception text in 13 languages; Dovetail is English-only and was carrying all of them.

---

## Unchanged

Everything from v1.0.0: controller detection and translation, guided calibration, per-game
profiles, stick-feel presets, the tray app, and automatic ViGEmBus and HidHide installation.
252 automated checks still pass on every build.

## Known limitations

**Call of Duty: Black Ops III is still untested** — recorded as pending install, not as a
failure. The title was not present on the test machine and its validation pass has not been
run. Sekiro: Shadows Die Twice remains the game validated in-game.

**Rumble is still not driven.** The channel exists on both sides but nothing is wired between
them.

**The installer is not code-signed.** SmartScreen will warn on first run — click *More info*
then *Run anyway*. Signing needs a certificate the project does not have.
