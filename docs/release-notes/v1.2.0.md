**Dovetail can now update itself.**

From this version on, a new release is one click away: open Dovetail's settings, go to
**Updates**, select **Check for updates**, then **Install update**. If you are on v1.1.0 or
earlier, install this one by hand — those versions have no updater to do it for you.

---

## Download

**[Get Dovetail from the download page](https://isaac-onyango-dev.github.io/Dovetail/)** —
download `DovetailSetup-1.2.0.exe`, run it, done. It installs over v1.1.0 in place and keeps
your calibration.

A portable `.zip` is still attached for anyone who would rather not install anything.

---

## What's new

**In-app updates.** Settings has a new **Updates** tab. It shows the version you have, checks
Dovetail's GitHub releases for a newer one, and installs it for you:

- The download shows a progress bar and a percentage the whole way, so it is always clear
  something is happening.
- The installer is checked against GitHub's own SHA-256 checksum before it runs. A file that
  doesn't match is deleted, not installed.
- Windows asks for permission once. Dovetail then closes, the installer shows its own progress
  window, and Dovetail opens again by itself when the update is done.
- If you say no to the permission prompt, nothing changes and you can try again.

**When it can't update automatically, it says so.** If GitHub can't be reached, the release
has no installer or checksum, the download fails, or the installer itself fails, Dovetail tells
you what went wrong and opens the
[Dovetail download page](https://isaac-onyango-dev.github.io/Dovetail/) in your browser so you
can update by hand. It never sends you to the GitHub releases page.

**Portable copies point you to the download page.** A copy run from the portable zip wasn't
installed, so running the installer would put a second copy in Program Files rather than
update it. The Updates tab says so and offers the download page instead.

**"Update information" in Windows Settings** (Apps → Dovetail) now links to the download page
instead of the GitHub releases page.

## Unchanged

Controller detection and translation, guided calibration, per-game profiles, stick-feel presets,
the tray app, and automatic ViGEmBus and HidHide installation. 262 automated checks pass on
every build (10 new ones cover how the updater reads a release).

## Known limitations

**Updates only happen when you ask.** Dovetail doesn't check in the background.

**Call of Duty: Black Ops III is still untested** — recorded as pending install, not as a
failure. Sekiro: Shadows Die Twice remains the game validated in-game.

**Rumble is still not driven.**

**The installer is not code-signed.** Downloading it from a browser, SmartScreen will warn on
first run — click *More info* then *Run anyway*. Windows' permission prompt during an in-app
update shows the publisher as unknown for the same reason.
