**Dovetail has its own icon now, everywhere.**

A small fix release. Until now the Dovetail mark only showed in the notification area. The
taskbar, the window title bar, the Start Menu and desktop shortcuts, Explorer and Add/Remove
Programs all showed Windows' default program icon instead.

---

## Download

**[Get Dovetail from the download page](https://isaac-onyango-dev.github.io/Dovetail/)** —
download `DovetailSetup-1.2.1.exe`, run it, done. It installs over any earlier version in
place and keeps your calibration.

On v1.2.0, you can also update from inside Dovetail: Settings → **Updates** →
**Check for updates** → **Install update**.

A portable `.zip` is still attached for anyone who would rather not install anything.

---

## What's fixed

**The app icon.** `Dovetail.exe` now carries the Dovetail mark at every size Windows asks for,
from 16 to 256 pixels. The taskbar, title bar, shortcuts, Explorer and Add/Remove Programs all
pick it up. The installer itself shows the mark too.

If you're updating and Windows still shows the old default icon for a while, that's Windows'
icon cache. It clears itself; signing out and back in clears it straight away.

## Also new

**A proper download page.** [isaac-onyango-dev.github.io/Dovetail](https://isaac-onyango-dev.github.io/Dovetail/)
now has one download button for the latest installer, the release notes, a live download count,
and straight answers about which pads and games have been tested.

---

## Unchanged

Controller detection and translation, guided calibration, per-game profiles, stick-feel presets,
the tray app, in-app updates, and automatic ViGEmBus and HidHide installation. 262 automated
checks pass on every build.

## Known limitations

**Call of Duty: Black Ops III is still untested** — recorded as pending install, not as a
failure. Sekiro: Shadows Die Twice remains the game validated in-game.

**Rumble is still not driven.**

**The installer is not code-signed.** Downloading it from a browser, SmartScreen will warn on
first run — click *More info* then *Run anyway*.
