Why it exists

Your game says no controller is connected.

Most budget gamepads speak an older language than the one modern games listen for. The game looks for an Xbox controller, doesn't find one, and ignores the pad entirely. Dovetail sits in between and translates.

IN · DirectInput / HID

Your gamepad

Any USB pad Windows recognises as a game controller.

DOVETAIL

Translation

Reads the pad's raw HID reports and maps them using the calibration you recorded.

OUT · XInput via ViGEmBus

Xbox 360 controller

A virtual controller the game detects as the real thing. No wrapper, no launch options, no per-game DLL.

Dovetail also hides the original pad from games with HidHide, so a game can't grab the raw pad instead of the virtual one.

Install

A few minutes, start to finish.

Everything Dovetail needs is either in the installer or fetched for you on first run. The .NET runtime is bundled.

  1. Run the installer

    Windows may say Windows protected your PC because the installer isn't code-signed yet. Select More info, then Run anyway.

  2. Let it add two drivers

    On first run Dovetail downloads ViGEmBus and HidHide from their developer's own releases. Windows asks for permission once.

  3. Calibrate your pad

    A short wizard asks you to press each button and move each stick, so the controls match your hardware.

  4. Start your game

    It sees an Xbox 360 controller. Two pads show up as player 1 and player 2.

What it does

Small tool. Does the whole job.

Guided calibration

A wizard measures rest noise, stick range and triggers, then saves a profile for each player.

Per-game profiles

Deadzone, saturation and response curve per game, layered over your calibration without changing it.

Stick-feel presets

Standard, Precise, Responsive and Full range, or tune by hand. A running game picks up changes within a second.

Lives in the tray

Live status for each controller, naming, re-calibrate, and notifications from the notification area.

Drivers handled for you

Detects, downloads, verifies and installs ViGEmBus and HidHide, and can repair them later.

Reversible uninstall

Removes only what Dovetail added, writes a restore point first, and keeps your calibration.

Requirements

What your PC needs.

Only the first one is on you. Dovetail installs the other two on first run. It runs as a normal user and asks for admin rights only while setting up drivers.

You provide

Windows 10 or 11, 64-bit

Nothing else. No macOS, Linux or ARM build.

Installed for you

ViGEmBus

The driver that creates the virtual Xbox controller. Without it there is nothing for the game to see.

Installed for you · not optional

HidHide

Hides the real pad from games. Without it, a game that checks both can grab the raw pad and ignore Dovetail. We found that out on the first real game we tested.

FAQ

Straight answers.

Will it work with my controller?

Probably, but it hasn't been checked. The one receiver tested end to end is the Shanwan "Twin USB Joystick" (VID 0810, PID 0001), with two pads acting as two separate players.

Calibration measures whatever your pad actually sends, so any USB gamepad with a standard HID descriptor should work once it's calibrated. Tried another pad? Tell us whether it worked.

Which games have been tested?
Sekiro: Shadows Die TwiceWorks
Detection, controls and two players confirmed in game.
Call of Duty: Black Ops IIINot tested yet
It wasn't installed on the test machine. That doesn't mean it fails.

Any game that supports an Xbox 360 controller should see Dovetail's virtual one, but only Sekiro has been confirmed.

Why does Windows warn me about the installer?

The installer isn't code-signed yet, so SmartScreen doesn't recognise it. Select More info, then Run anyway. Dovetail is open source, and each release lists a SHA-256 checksum you can check the download against.

Why does it need HidHide? Can I skip it?

No. Without HidHide the real pad stays visible to games alongside the virtual Xbox controller. Many games check both, pick up the real pad, and ignore Dovetail even while it's translating perfectly.

Can I undo everything?

Yes. Uninstall from Add/Remove Programs or the Start Menu. It removes Dovetail's auto-start entry and its own HidHide settings, un-hides any device Dovetail hid, and writes a restore point first.

It keeps your calibration in %LOCALAPPDATA%\Dovetail in case you come back, and leaves ViGEmBus and HidHide installed, since other programs may use them.

Does it update itself?

From v1.2.0 on, yes, when you ask it to: open Settings → Updates → Check for updates. It doesn't check in the background. Copies run from the portable .zip point you back to this page instead.

Can I use it without installing?

Yes. Each release also includes a portable .zip. Keep Dovetail.exe, dovetail-diag.exe and dovetail-engine.exe in the same folder, because they rely on each other.

Does rumble work?

Not yet. Rumble isn't sent to the pad.

Something went wrong.

Open an issue on GitHub with your pad's name, your Windows version and what you saw. dovetail-engine deps paths shows which folders Dovetail is using, which helps.
