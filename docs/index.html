Dovetail

Fits your pad to the game.

Dovetail makes a cheap USB gamepad work in PC games that only accept an Xbox controller.

Download for Windows

Free. Windows 10 and 11, 64-bit.

Your game says no controller is connected.

Most budget gamepads use an older input standard called DirectInput. Modern games only look for XInput, the Xbox controller standard, so they don't see the pad at all. Dovetail sits between the two.

Your gamepad

Any USB pad Windows recognises as a game controller.

Dovetail

Reads the pad's raw input and translates it, using the calibration you recorded.

Xbox 360 controller

A virtual controller the game detects as the real thing. No per-game setup.

Dovetail also hides the original pad from games, so a game can't pick up both it and the virtual controller.

Install in a few minutes

Everything Dovetail needs is either in the installer or downloaded for you on first run.

  1. Run the installer

    Windows may say Windows protected your PC, because the installer isn't code-signed yet. Select More info, then Run anyway.

  2. Install the two drivers

    On first run, Dovetail downloads ViGEmBus and HidHide from their developer's own releases. Windows asks for permission once.

  3. Calibrate your pad

    A short wizard asks you to press each button and move each stick, so the controls feel right on your hardware.

  4. Start your game

    It sees an Xbox 360 controller. Two pads show up as player 1 and player 2.

What it does

Guided calibration
Measures your sticks, triggers and buttons, then saves a profile for each player.
Per-game profiles
Set deadzone, sensitivity curve and range for each game without touching your calibration.
Stick feel presets
Standard, Precise, Responsive and Full range. Changes apply to a running game within a second.
Two players
Two pads become two separate Xbox controllers.
Lives in the tray
See each controller's status, rename it, re-calibrate or repair the drivers from the notification area.
Clean uninstall
Removes only what Dovetail added and keeps your calibration in case you come back.

Will it work with my pad?

Dovetail needs Windows 10 or 11 (64-bit). Nothing else to install first.

It has been tested end to end with the Shanwan Twin USB Joystick receiver (VID 0810, PID 0001). Calibration measures whatever your pad actually sends, so other standard USB gamepads should work too, but they haven't been verified yet.
