The problem / 01

Same pad. Different game.

Budget gamepads speak an older language, DirectInput. Most modern games only listen for Xbox controllers, XInput. So they ignore your pad completely.

Getting started / 02

Three levels. No boss fight.

  1. Level 101

    Install

    Run the installer. On first launch Dovetail sets up its two small drivers for you — Windows asks permission once.

  2. Level 202

    Calibrate

    A short wizard asks you to press each button and move each stick, so the controls match your exact pad.

  3. Level 303

    Play

    Start your game. It sees an Xbox 360 controller. Two pads? Player 1 and Player 2.

TipWindows may show "Windows protected your PC" the first time, because the installer isn't code-signed yet. Click More info, then Run anyway. The whole source is on GitHub if you'd like to check it first.

Loadout / 03

Everything in the box.

No config files, no command line, no hunting for drivers.

Slot 1

Guided calibration

Dovetail measures your pad instead of guessing: where the sticks rest, how far they travel, which button is which. It saves a profile for each player.

Slot 2

Two players

Two pads become two separate Xbox controllers. Couch co-op, sorted.

Slot 3

Stick feel

Standard, Precise, Responsive or Full range. A running game picks up changes within a second.

Slot 4

Per-game profiles

Different deadzone or response curve for each game. Dovetail switches when the game starts.

Slot 5

Drivers handled

Downloads, verifies and installs ViGEmBus and HidHide for you, and repairs them if they break.

Slot 6

Stays out of the way

Lives in the tray with live controller status and notifications. Updates itself when you ask. Uninstalls cleanly, writes a restore point first, and keeps your calibration in case you come back.

Help / 07

Questions people ask.

?Will it work with my controller?

Probably, but it hasn't been checked. The one receiver tested end to end is the Shanwan "Twin USB Joystick" (VID 0810, PID 0001).

Calibration measures whatever your pad actually sends, so other standard USB gamepads should work once calibrated. Let us know how yours does.

?Which games does it work with?

Games that accept an Xbox 360 controller should see Dovetail's. So far Sekiro: Shadows Die Twice is confirmed in game. Call of Duty: Black Ops III hasn't been tested yet, which doesn't mean it fails.

?Why does Windows warn me about the installer?

It isn't code-signed yet, so SmartScreen doesn't recognise it. Click More info, then Run anyway. Each release lists a SHA-256 checksum if you'd like to check the download.

?Do I need to install anything else?

No. The installer brings everything, and Dovetail sets up its two drivers, ViGEmBus and HidHide, on first run. Windows asks for permission once.

?Why does it need HidHide? Can I skip it?

No. Without HidHide the real pad stays visible next to the virtual Xbox controller. Many games check both, grab the real pad, and ignore Dovetail even while it's translating perfectly.

?Can I undo everything?

Yes. Uninstall from Add/Remove Programs or the Start Menu. It removes what Dovetail added, un-hides your pad, and writes a restore point first. Your calibration is kept in case you come back, and the two drivers stay installed since other apps may use them.

?Does it update itself?

From v1.2.0 on, when you ask: Settings → Updates → Check for updates. It never checks in the background.

?Can I use it without installing?

Yes. Each release has a portable .zip. Keep its three .exe files in the same folder; they rely on each other.

?Does rumble work?

Not yet. Vibration isn't sent to the pad.

?Something went wrong.

Open an issue on GitHub with your pad's name, your Windows version and what happened.
